# Requirements Ledger — operations, security, governance, intelligence, observability — nse-botonly

Merged 2026-08-08. Raw rows in slice: 266 (78 nse-botonly + 188 crypto-bot, across the five target
categories in `crypto-bot-and-nse-botonly.md`). Merged rows: 77 (76 nse-botonly + 1 flagged exception,
see below). crypto-bot rows collapsed as mirror duplicates: 188 (9 are the current project's own
already-built capture-layer code, cited but not re-listed; 3 genuinely unique unbuilt gaps noted in
Cross-references; the remaining 176 duplicate `research-corpus.md` design prose already covered by the
sibling PARTIAL files or the other category slices).

**Caveat that travels with every PRIOR-ART row below:** PRIOR-ART means working code exists. It never
means proven. `prior-attempts-postmortem.md` §3.2–3.3 records that this project's own documentation has
outgrown its validated results before — the substitution of a synthetic target for the real validation
target is the specific, cited failure mode.

**One exception to the category filter, made deliberately.** Row OGN-077 below (Category: `strategy`,
not one of this slice's five categories) is included anyway because the task brief flagged it by name:
`nse-botonly`'s own `BACKLOG B42` records that its top-level strategy router — the "main AI brain" —
was never built, and the current project has the identical hole (no `strategy/`, `portfolio/`, or
`arbiter/` directory exists under `src/`, confirmed by direct search 2026-08-08). It is the same gap
twice, in the two most complete systems in the account, and it would have been a mistake to drop it on
a technicality.
